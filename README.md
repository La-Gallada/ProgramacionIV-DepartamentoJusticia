# Departamento de Justicia

Sistema web desarrollado como proyecto universitario para gestionar procesos internos de un Departamento de Justicia.

## Tecnologías

- ASP.NET Core MVC
- .NET 8
- C#
- Entity Framework 6 clásico
- SQL Server / LocalDB
- Razor Views
- Bootstrap / CSS
- Git y GitHub

## Funcionalidades

- Gestión de agentes
- Gestión de casos judiciales
- Gestión de sospechosos
- Gestión de evidencias
- Gestión de operativos
- Gestión de tribunales
- Gestión de audiencias
- Gestión de usuarios
- Login y sesiones
- Protección de rutas
- Bitácora de accesos
- Búsquedas y filtros
- Reglas de negocio y cálculos automáticos

## Arquitectura

View -> Controller -> Service -> Entity Framework 6 -> SQL Server
